# 💘 Telegram-бот знакомств

Бот в духе «Дайвинчика»: анкеты с фото, поиск людей в своём городе или по всему
миру, лайки/дизлайки, уведомление о взаимной симпатии, список тех, кто вас
лайкнул, редактирование анкеты и настройки поиска.

## Возможности

- 📝 Пошаговая регистрация: имя, возраст, пол, кого ищете, город, описание, фото
- 🔍 Просмотр анкет с инлайн-кнопками ❤️ / 👎 / ⚠️ «Пожаловаться»
- 💞 Взаимный лайк → обоим приходит уведомление с контактом (юзернейм или ссылка)
- ❤️ «Кто меня лайкнул» — очередь тех, кто уже поставил вам лайк
- ✏️ Редактирование любого поля анкеты (имя, возраст, город, описание, фото, пол, предпочтения)
- ⚙️ Настройки поиска: только свой город / все города, возрастной диапазон партнёра
- 🚫 Жалоба — скрывает анкету пользователя от вас навсегда
- Все данные хранятся локально в SQLite, без внешних сервисов

## Установка

1. Установите Python 3.10+
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Получите токен бота у [@BotFather](https://t.me/BotFather) (команда `/newbot`)
4. Задайте токен одним из способов:
   - через переменную окружения:
     ```bash
     export BOT_TOKEN="123456:ABC-ваш-токен"
     ```
   - или впишите его прямо в `config.py` вместо заглушки
5. Запустите бота:
   ```bash
   python bot.py
   ```

Бот использует long polling — сервер с открытым портом не нужен, достаточно,
чтобы процесс был запущен (можно на VPS, Railway, PythonAnywhere, дома и т.д.).

## Структура проекта

```
dating_bot/
├── bot.py              # точка входа, запуск polling
├── config.py           # токен и путь к БД
├── database.py         # вся работа с SQLite (async)
├── keyboards.py        # клавиатуры и оформление карточек анкет
├── states.py           # FSM-состояния (регистрация, редактирование, настройки)
├── handlers/
│   ├── registration.py # /start и создание анкеты
│   ├── browsing.py     # просмотр анкет, лайки, дизлайки, жалобы, мэтчи
│   ├── likes.py         # "Кто меня лайкнул"
│   ├── edit.py          # редактирование анкеты
│   ├── settings.py      # настройки поиска (город/возраст)
│   └── menu.py          # "Моя анкета", "Помощь"
└── requirements.txt
```

## Как расширять

- **Гео-поиск по расстоянию**: добавьте поля `latitude`/`longitude` в таблицу
  `users`, принимайте геолокацию (`message.location`) и считайте расстояние
  (например, через `geopy`).
- **Модерация фото**: перед сохранением анкеты добавьте шаг подтверждения
  администратором (сохраняйте `is_active = 0` до одобрения).
- **Несколько фото в анкете**: заведите отдельную таблицу `photos` с `user_id`
  и `file_id`, показывайте медиагруппой.
- **Инлайн-статистика/админка**: используйте `get_stats()` из `database.py`
  как основу для админ-панели.

## Важно

- Файл базы данных `dating_bot.db` создаётся автоматически при первом запуске.
- Для продакшена рекомендуется вынести токен только в переменные окружения,
  не хранить его в `config.py` при публикации кода (например, в Git).
